what it is

One agent, every surface it needs.

OtoClaw doesn’t bolt features onto a chat window. It's a daemon with a real pipeline — planning, routing, sub-agents, judgment — wired into the tools that pipeline actually needs.

Terminal, and a real native app

A bespoke terminal UI for the keyboard-first workflow, plus a genuine native desktop app — no Chromium wrapper. Both speak the same protocol to the same local daemon, so nothing ever gets out of sync.

Sub-agent orchestration

The main agent spawns sub-agents on its own, briefs them precisely, and merges their work back — researching and building in parallel.

Deep MCP integrations

Blender modeling, Unity game dev, GitHub, YouTube — wired in as MCP tool servers, not one-off scripts.

Browser bridge, orange cursor

A custom extension drives Gmail, Calendar, and the sites OtoClaw just built — with its own visible cursor, orange and unmistakably itself, so you can watch it act.

Sees your screen

Screen reading and vision let it look at what you’re looking at, then reason about it instead of guessing blind.

Open source, Apache-2.0

Local-first and source-open by design — no cloud dependency, no lock-in. Fork it, audit it, run it fully offline against your own models.
